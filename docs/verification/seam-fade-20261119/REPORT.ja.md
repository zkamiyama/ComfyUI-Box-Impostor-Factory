# Box Impostor の境界フェード検証

2026-11-19

顎の継ぎ目では元の Depth の段差に応じて色の取得元が切り替わっていました。追加した L3 はこの局所の色差を弱めましたが、首の暗部と +45°の顔や髪の重なりは残り、髪の暗い斑点も増えました。全体を改善する設定としての採用は見送り、比較基準の K を維持します。

## 条件と実装

同じ F の Box データを3D-Inspector の生成済み HTML で描画しました。描画サイズは 1024×1024、正投影カメラの角度は 0°・−30°・+45°です。K/L1/L2/L3 の各角度でカメラ行列とアルファが一致しました。[L1/L2 の比較記録](seam-fade-initial-provenance.json)、[L3 の比較記録](L3-final-provenance.json)、[L3 のデータ同一性](L3-final-viewer-payload-identity.json)に照合結果を保存しています。

| 記号・設定 | 変更 |
|---|---|
| K `view` | 比較基準。角度の重みは cos⁸、深度差 2〜3 texel で可視候補を除外 |
| L1 `view-fade` | 候補の信頼度が下がると native の色へフェード |
| L2 `view-soft` | L1 の角度の重みを cos⁴ にし、深度差のフェードを 2〜6 texel に拡大 |
| L3 `view-feather` | K を基に元画像の深度が急変する付近の相対重みを低減 |

変更対象は交差位置で選ぶ色です。保存済みの形状・深度、native の交差判定と出力アルファは維持しています。

## L1/L2 の実画像

下表は共通の不透明な頭部マスクを 3px 縮小して測った、K からの RGB 値の平均絶対差です。値域は 0〜255 で、画質や形状の正解率を表す値ではありません。[測定値](seam-fade-initial-provenance.json)

| 角度 | 対象画素 | L1 の平均差／変更画素 | L2 の平均差／変更画素 |
|---|---:|---:|---:|
| 0° | 14,080 | 0.02306／27 | 0.02625／45 |
| −30° | 15,557 | 0／0 | 3.09576／10,586 |
| +45° | 10,801 | 0.00296／5 | 0.41107／204 |

L1 の斜め画像は K とほぼ同じでした。L2 は首の暗部を変えましたが、境界全体の解消は確認できていません。

正面の生成 RGB との比較には従来と同じ 10,936 画素の固定マスクを使いました。平均絶対誤差は K が 0.60796、L1 が 0.63232、L2 が 0.58452 でした。これは正面画像をどれだけ保ったかの測定で、3D ジオメトリの精度評価ではありません。[正面の参照とマスク](seam-fade-initial-provenance.json)

## 首と顎の境界診断

−30°画像の首の領域 `[510,202,591,259]` は、K/L1/L2 とも 4,617 画素すべてが不透明でした。透明な穴による黒さではありません。L1 のこの領域は K と RGB も一致し、L2 では 2,902 画素が変わりました。[アルファと暗部の分類](neck-seam-classification.json)

診断用シェーダーで K の候補の重みと交差位置を読み出しました。表の座標は 1024×1024 画像の左上を原点とし、RGB は 0〜255 です。診断の色は元の Inspector キャプチャと差分 0 で一致しました。[読み出した値](shader-tests/boundary/boundary-probes.json)

| 位置 `(x,y)` | 主な投影面と重み | K の RGB |
|---|---|---|
| 首 `(526,225)` | +Z 98.7805%、−X 1.2195% | 64, 41, 28 |
| 首 `(527,225)` | +Z 100% | 148, 102, 75 |
| 首 `(528,225)` | +Z 100% | 232, 167, 145 |
| 顎 `(541,224)` | −X 100% | 207, 142, 104 |
| 顎 `(541,225)` | +Z 98.7805%、−X 1.2195% | 236, 173, 152 |

首ではヒット位置と元画像の参照位置が大きく動き、ほぼ同じ +Z 投影の中で色差が生じています。一方、顎の隣接画素では交差位置の変化が小さいまま、主な色の取得元が −X から +Z に切り替わりました。

顎の +Z 第一面までの深度差は 16.60→1.49 texel となり、+Z が可視候補に入りました。元の +Z Depth にも周辺の傾斜より大きい 787→891 texel の段差がありました。深度値は 1024 を掛けて texel 単位に換算しています。色の継ぎ目はこの深度の段差と候補の選択に伴って現れています。[元 Depth の近傍値](shader-tests/boundary/source-depth-neighbors.json)

L2 は首の `(526,225)` を `[100,82,65]` に変えましたが、次の `(527,225)` と `(528,225)` は K と同じ色でした。暗さを数える閾値や色の変化だけから、再構成の精度が上がったとは判断できません。[元画像](raw/L2-view-soft/yaw-m30_000.png)

## 合成テストでのフェード

交差位置と native の代替色を固定し、製品と同じ色選択処理に候補の脱落条件を与えました。下表は隣接する試験条件間の RGB 最大差です。実モデルの raymarch を固定値に置き換えた独立テストで、実画像の改善量ではありません。[合成テスト](shader-tests/controlled-dropout/fade-report.json)

| 試験条件 | K | L1 | L2 |
|---|---:|---:|---:|
| 単独候補の深度差を 0.05 texel ずつ変更 | 138 | 11 | 3 |
| 45°で片方の coverage を 0.001 ずつ変更 | 115 | 5 | 5 |
| 不均等な角度で coverage を 0.000025 ずつ変更 | 170 | 72 | 4 |

L1/L2 は有効な単独候補の色を 0°と 45°で保持しました。ただし不均等な角度では、L1 の切り替わりが狭い条件範囲に残っています。既存の native/view/dominant の合成画像比較では、全 9 姿勢の最大差は RGB 値 1 でした。[従来の描画との比較](shader-tests/legacy-output-comparison.json)

## L3 の実画像と採否

`view-feather` は元画像の深度を U/V 方向に調べ、周囲の傾斜より大きな深度の急変だけを対象にします。半径 6 texel の範囲で相対重みを下げますが、有効な投影面が 1 つだけならその色を保ちます。native に戻る判定には低減前の重みを使います。最終 helper は `b1cb7d3f7e0dd6bffe0101f3db9638e1bce2067d79c91b17380f0e0481c87df9` です。

最終 L3 では、顎の `(541,224)` と `(541,225)` の RGB 平均絶対差が 36→12.33333 に下がりました。同じ 2 行の固定した 10 列 `x=537…546` の平均も 36.33333→11.7 でした。これは局所の継ぎ目の色差です。正面の頭部マスクでは K との RGB 差が 0 で、固定マスクの誤差も 0.60796 のままでした。[最終比較記録](L3-final-provenance.json)

首の同じ領域は L3 でも全画素が不透明です。暗部の `(526,225)` は `[64,41,28]` から `[57,31,17]` になり、暗い領域は残りました。+45°では顔や髪の重なりが残り、髪の暗い斑点も増えたため、全体を改善する設定としては採用しません。[−30°](raw/L3-view-feather-final/yaw-m30_000.png)・[+45°](raw/L3-view-feather-final/yaw-p45_000.png)

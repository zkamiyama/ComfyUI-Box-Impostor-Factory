# Direct3D-V3 調査ログ

## 記録の範囲

2026年11月21日の調査終了後、保持されているツール記録と保存原文から作成した。検索の正確な実行時刻は記録していない。新しい検索やダウンロードは行っていない。

## 検索とリンク追跡

第1検索枝（direct3d_sources）は、3クエリを1バッチのsystem1_search_queryで実行した。返却された7件はバッチ全体の結果であり、個別クエリへの帰属は復元していない。クエリ文字列をセミコロンで連結した当時の報告JSONを、digest.py addへそのまま渡した。第三者サイトのヒットも削除せず残したが、技術的な判断の根拠には使っていない。

第2検索枝（direct3d_memory_review）は独立にコードとメモリー使用経路を調べた。初期検索の結果は報告されたが、検索語と全ヒットの詳細ログが保持されていないため、queries.jsonlへ推測で補っていない。

親エージェントはREADMEをWebで開き、GitHubのファイル取得で公式ソースを確認した。そのほかは対象ファイルを指定した読み取りで、広い検索は追加していない。memory_reviewは固定commitのREADMEと公式サンプル法線画像も確認した。

## 取得経路と失敗

| 対象 | 経路と結果 | 保存状態 |
|---|---|---|
| GitHub READMEとコード | GitHub fetch_fileで親が取得、ローカル原文を本作業で確認 | 原文5ファイルを保存済み |
| プロジェクトページ | Web openが失敗し、URL読み取りで取得 | 閲覧済み・この資料束には未保存 |
| Hugging Faceのモデル情報 | Web openが失敗し、URL読み取りでAPIと設定を確認 | 閲覧済み・この資料束には未保存 |
| ACM DOI | Web openで取得できず、公式arXivの本文へ進んだ | ACM本文は取得できていない |
| arXiv本文 | 検索結果の識別子から公式abs/HTMLを読んだ | 閲覧済み・この資料束には未保存 |
| 512の重みヘッダー | 公開URLへのRange読み取りでヘッダーを確認 | ヘッダーはこの資料束に未保存 |
| 公式サンプル法線画像 | memory_reviewがURL画像を閲覧 | この資料束には未保存 |

fetch-log.jsonlのOKは、この資料束に存在して内容を確認した5原文だけを表す。外部ページの未保存と取得失敗を同一視していない。親が示したGitHub commitは`b93ad9c0a451729bb76b60ce69cbf076e76e95af`、モデルrevisionは`1f42e11da6efbc8cc0661c62132b0533c338e3d3`。後者のモデル原文はこの資料束に含まれない。

## 原文の抜き書きと文書化

report.pyとdigest.pyの公式スクリプトで、抜き書きが指定した原文行に存在するか照合してHTMLを生成した。表示HTMLでは、引用の前後を自動転載する部分だけを生成後に取り除いた。短い抜き書き、行番号、原文URLは残した。保存原文と公式スクリプトは変更していない。

新規本文はyomiyasuの検査対象とし、照合記録も残す。検査の実行やハッシュ照合は、記述内容の正しさを自動で保証するものではない。

## 不明・未調査

第2検索枝の詳細履歴がないため、この検索ログは完全ではない。異なる下調べを並行したもので、同じ母集団を独立検索した記録としては扱わない。検索の飽和率は算出していない。16 GBでの第三者の成功例、非公式モデル配布、量子化版は探していない。

## 区切った理由

公開範囲・入力条件・単段ロードの根拠が固定した公式READMEとコードにそろったため、調査を区切って実行に進んだ。検索の網羅性や飽和は判定していない。

今回の生成物の良否と表示上の問題は、実験記録で確認する。公式READMEの入力推奨を、個別の表示不具合の原因説明として使わない。
